## 開發項目

### Line Message API

* 目標：
  * 能夠攔截line user 送往line Office的訊息。
  * 能夠將driver和Line user的ID做綁定。
  * 能夠發送訊息(文字、圖片)至line user。
    1. 已完成文字發送。
  * 收到或是發送的資料都必須在資料庫留存。

### 多國語言套件

 * 目標：
   * 支援多國語言，讓使用者介面或是後端系統都能用中英文顯示/切換。

### 帳務系統

* 目標：
  * 能顯示完整的帳款資料
    * 查詢某位司機的帳款明細
    * 能夠手動入帳，包含(新增、刪除、修改)

### 過帳系統

### 罰單/ETC/停車費作業

 * 目標：
   * 在進行罰單批次作業時，能一併入帳，並且以line方式通知司機。

### 營業稅申報作業

 * 目標：
   * 能夠根據年3、6、9、12月，根據所選定的車行。自動產生報表

### GPS定位系統

 * 目標：

   ​	能夠抓取目前安裝的GPS座標，並且分析以下資訊

   1. 三日以上不上線(異常現象)。
   2. 長時間停留的所在位置(表示經常出沒地方)
   3. 每周行車距離低於300KM。
